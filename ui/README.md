# ui/

Adjuster UI — UiPath Apps, or our own front-end reading from Data Fabric (decide at kickoff).

Screens:
- **Queue** sorted by recommendation / score.
- **Case screen**: stage timeline, parallel lanes per agent per round, Judge decisions in plain words,
  map (house + flood polygon + distance), photos with per-photo verdict, contribution chart, replay slider.

Adjuster controls: fix an extracted field (re-run from that stage), reject a piece of evidence, ask a free
question (becomes an agent task), approve important actions (Action Center).
